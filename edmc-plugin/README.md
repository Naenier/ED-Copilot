# Связь ED Copilot с EDMarketConnector

EDMC — самостоятельное приложение, а не сервер с API синхронизации. ED Copilot поддерживает два способа отправки данных. Выберите один основной источник отправки в разделе «Интеграции»:

- **ED Copilot**: Copilot самостоятельно отправляет публичные наблюдения в EDDN и личные данные в Inara по вашему ключу. Отключите соответствующую отправку в EDMC, если запускаете его одновременно.
- **EDMC**: отправку в Inara и EDDN выполняют настроенные плагины EDMC. Copilot не дублирует их запросы. Плагин из этой папки связывает EDMC с Copilot для отображения состояния соединения и последних наблюдений.

Это не импорт аккаунта EDMC. Плагин не заимствует его Frontier client ID, токены OAuth или ключ Inara и сам не отправляет запросы в интернет. Авторизацию Frontier в Copilot и EDMC настраивают отдельно; уже работающий EDMC можно оставить единственным отправителем.

## Установка плагина

1. В EDMC откройте **Settings → Plugins → Open**. Закройте EDMC.
2. Скопируйте папку `EDCopilot` целиком в открытую папку плагинов. Обычный путь Windows: `%LOCALAPPDATA%\EDMarketConnector\plugins\EDCopilot\load.py`.
3. Запустите Copilot, выберите режим **EDMC** в «Интеграциях» и скопируйте код сопряжения.
4. Запустите EDMC. Откройте **Settings → ED Copilot**, вставьте код и включите «Связать с ED Copilot на этом компьютере».
5. В настройках самого EDMC включите нужные плагины EDDN/Inara. Для Inara укажите личный API-ключ, полученный на странице своего командира Inara.
6. После нового события журнала или обновления данных в EDMC Copilot покажет время последнего контакта. Даже без новых событий плагин передаёт сигнал присутствия примерно каждые 15 секунд.

Плагин рассчитан на Copilot, работающий на этом же компьютере с обычным портом **7122**. Он передаёт данные только на `http://127.0.0.1:7122/api/integrations/edmc`, с кодом в заголовке `X-EDCopilot-Token`. Другие адреса и перенаправления запрещены; системный прокси не используется. При смене кода сопряжения обновите его в EDMC. Код не публикуют в GitHub.

В локальном предварительном просмотре передаются имя командира, версия игры, выбранные публичные события (системы, станции, сканы, состав колец, сигналы), а также публичные цены рынка из CAPI. Баланс, миссии, личная репутация, склад флотоносца, пароли и токены Frontier отфильтрованы. Когда Copilot закрыт, EDMC продолжает работать и отправлять данные своими обычными плагинами; локальная очередь ограничена и не блокирует окно EDMC.

## Что отправляет Copilot в EDDN

В собственном режиме Copilot отправляет свежие публичные события `Location`, `FSDJump`, `CarrierJump`, `Docked`, `Scan`, `SAASignalsFound`, содержимое новых `Market.json`, `Outfitting.json` и `Shipyard.json`, а также проверенные станционные данные CAPI. Это обновляет общую сеть наблюдений, которой пользуются сторонние сайты; публикация не означает мгновенное обновление каждого сайта.

EDDN не принимает личный профиль, миссии, баланс и личный склад. CAPI-цены используются только когда командир пристыкован, название системы, станция и MarketID совпадают с текущим журналом. Неполные или устаревшие данные пропускаются. Нужны наблюдения из Live-галактики; данные беты и тестовых журналов не публикуются в рабочие схемы. Идентификатор отправителя — имя командира; сама сеть EDDN обфусцирует его перед ретрансляцией.

Ошибка сети оставляет сообщение в очереди Copilot для повторной попытки не раньше чем через минуту. Ошибки формата или неподдерживаемой схемы требуют обновления приложения; бесконечные повторы такого сообщения не выполняются.

## Если связь не появляется

Проверьте, что Copilot запущен на порту 7122, выбран режим EDMC, код в обеих программах совпадает, а папка плагина не вложена дважды. После установки или обновления `load.py` перезапустите EDMC. В **Settings → Plugins** плагин должен присутствовать среди активных. Журнал EDMC содержит краткие сообщения о недоступности локального приложения или HTTP-ошибке, без кода и игровых данных.
