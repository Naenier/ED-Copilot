# ED Copilot 2.0.0

Полностью нативное приложение для Windows: интерфейс, обработка журнала, расчёты, синхронизация и оверлей написаны на Go. Для запуска достаточно распаковать архив и открыть **ED Copilot.exe**.

- Несколько колоний с независимыми стройками, очередями снабжения, ресурсами и поставками. Выбранная колония отображается в оверлее.
- Исправлены названия моделей кораблей; личное имя и регистрационный номер показаны отдельно.
- Нативные вкладки с добавлением, закрытием, перетаскиванием и прокруткой. Все разделы и формы поддерживают кириллицу.
- Сохранены торговля, поиск рынков, добыча, инженерия, флотоносец и планирование его маршрута, статистика, цели, энциклопедия, Frontier и отправка данных в Inara.
- Оверлей появляется только при фокусе игры. Для корабля, ТРП и Nomad панели сдвинуты вниз. Полноэкранный, оконный режим и окно без рамки; настройка и импорт палитры игры.
- Добавлены автоматические тесты логики, контрактов экранов, миграции профиля, имитации сетевых ответов и smoke-сценарии собранного приложения.

Настройки предыдущей версии импортируются при первом запуске. Исходные файлы профиля остаются на месте; версия 2 использует отдельные файлы сохранений. Для обновления полностью завершите старое приложение через значок в области уведомлений Windows.

Данные внешних сервисов могут запаздывать: перед полётом проверьте возраст котировки, спрос, доступность станции и ограничения площадки. Состав стройки и доступность колонизации подтверждаются в игре; неизвестные сведения не считаются нулевыми.
