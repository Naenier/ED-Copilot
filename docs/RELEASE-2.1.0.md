# ED Copilot 2.1.0

- Новое рабочее пространство: встроенная верхняя панель, настраиваемое левое меню с иконками, поиск Ctrl+K, отдельная панель подробностей и тонкие скроллбары.
- Калькулятор затрат для личного и эскадрильного флотоносцев: покупка, обязательные и дополнительные службы, приостановка, вместимость, прыжки, топливо, резерв и сравнение бюджетов. Планы типов независимы.
- Академия: девять курсов, 27 русскоязычных уроков по темам гайдов PTN, практикумы ED Copilot, задания, самопроверка, прогресс, закладки и сохранение места чтения.
- Установщик Windows с выбором папки, ярлыками и удалением программы с сохранением профиля. Переносимая версия также доступна.
- Go обрабатывает игровые данные и расчёты; локальный интерфейс работает в WebView2. Игровой оверлей остаётся нативным Win32 и появляется только при фокусе игры.

Перед обновлением завершите ED Copilot через меню значка в области уведомлений. Настройки и планы 2.0 сохраняются. При отсутствии Microsoft Edge WebView2 установщик предложит установить официальный Runtime.

Оценки калькулятора за 30 и 365 дней используют пропорции 30/7 и 365/7 недель. Цена и средний расход трития задаются отдельно; точный расход конкретного перелёта рассчитывается в маршруте флотоносца.
