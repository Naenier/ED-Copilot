# ED Copilot 2.8.4

- Carrier Trade shows full-hold runs with at least 400 million credits in estimated net profit. It compares regional markets and Rackham’s Peak across commodities.
- A run can combine purchases from stations in up to three systems. Fuel estimates account for the cargo on each jump.
- Working time separates carrier jumps, cargo loading, unloading and tritium preparation. Loading and selling can use different ships.
