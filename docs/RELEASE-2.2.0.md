# ED Copilot 2.2.0

## Новое

- **Торговля флотоносцем:** отдельный план рейса туда и обратно, оба типа носителя, тритий с резервом, вместимость, прыжки, время, содержание и оплата перевозчиков. Итоги включают прибыль владельца, прибыль за час, капитал, безубыточность, рентабельность и окупаемость.
- **Booze Cruise:** шаблон рейса к Rackham’s Peak с ограничением площадки M. Цена вина остаётся неизвестной до выбора котировки или ввода данных; Public Holiday подтверждается отдельно.
- **Энциклопедия:** категории, группы, поиск, страницы результатов и полные страницы сущностей. Добавлены изображения кораблей и портреты инженеров, связанные записи и удобное чтение статей.
- **Инженеры и рецепты:** полные страницы доступны из энциклопедии, инженерии и целей. Модули, чертежи и эффекты сгруппированы по семействам; рецепты показывают уровни, материалы и известный личный запас.
- **Товары и системы:** со страницы товара можно искать покупателей и продавцов либо открыть торговлю с предзаполненным товаром. Системы открываются как справочные страницы с копированием названия.
- **Маршрут флотоносца:** после подтверждённого прибытия следующая система может автоматически копироваться в буфер обмена для вставки через Ctrl+V. Управление функцией находится на странице маршрута.

## Сохранено и улучшено

Адаптивный оверлей по занятиям, несколько независимых колоний, инженерные планы, Академия, вход Frontier и отправка поддерживаемых событий в Inara. Справочные страницы загружают подробности по запросу; поиск и фоновые обновления сохраняют отзывчивость окна.

## Установка

Запустите `ED-Copilot-2.2.0-Setup.exe` или распакуйте `ED-Copilot-2.2.0-windows-amd64.zip`. Поддерживаются Windows 10/11 x64 и Microsoft Edge WebView2 Runtime; установщик предложит добавить компонент при необходимости. Go, Python и Node.js пользователю не нужны.

Перед обновлением полностью завершите прежнюю версию через меню «Файл» или значок в области уведомлений. Профиль 2.x, планы, подключения и прогресс сохраняются отдельно от папки программы.
