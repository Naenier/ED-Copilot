# ED Copilot 2.8.17

- Rebuilt **Trading → Routes** with the same search criteria as Inara's best trade routes, including Powerplay filters for both endpoints. Each card shows prices, volumes, distance, quote age, margins and applicable Powerplay bonuses for both stations.
- Select a route to copy the destination system. On arrival, Copilot copies the return stop. The trading overlay shows the station and the commodities to buy or sell.
- Hourly profit appears after the first completed round trip and uses elapsed time from the game's journal. Matching buy and sell events provide actual profit.
