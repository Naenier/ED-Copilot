# Вкладки, окно и справочные цены

## Открытые разделы

Стандартный набор — **«Обзор», «Цели», «Торговля», «Энциклопедия», «Статистика» и «Настройки»**.

- Нажмите **«+»** справа от полосы вкладок, чтобы добавить другой раздел.
- Крестик и средняя кнопка мыши закрывают дополнительную вкладку. «Обзор» и «Настройки» всегда остаются доступными.
- Перетащите вкладку мышью либо сфокусируйте её и нажмите **Alt+←/→**, чтобы поменять порядок.
- В меню «+» есть **«Восстановить стандартные вкладки»**.

Список открытых вкладок и их порядок сохраняются между запусками. Закрытие вкладки меняет навигацию: планы, личные цели, история и инструменты раздела сохраняются. Раздел снова доступен через «+»; переход из карточки или справки открывает его вкладку автоматически.

Кнопка **«? Помощь по разделу»** открывает встроенное руководство независимо от того, была ли его вкладка уже добавлена.

## Режим основного окна

В настольном приложении откройте **«Настройки → Режим окна приложения»**, выберите **«Режим отображения»** и нажмите **«Применить режим»**.

| Режим | Как выглядит |
| --- | --- |
| В окне | Обычная рамка Windows, свободное перемещение и изменение размера. |
| Полноэкранный | Основное окно занимает весь монитор. |
| Безрамочное окно | Без системной рамки, по размеру рабочей области монитора, с доступной панелью задач. |

**F11** переключает оконный и полноэкранный режимы; из безрамочного возвращает оконный. **Esc** возвращает обычное окно из полноэкранного или безрамочного режима.

Режим и обычный размер окна запоминаются между запусками. При изменении набора мониторов положение корректируется до доступной рабочей области. В режимах без системной рамки используйте кнопки заголовка приложения для сворачивания, возврата в окно и скрытия в область уведомлений. Полный выход — через меню значка ED Copilot.

Режим основного окна и игровой оверлей настраиваются отдельно. Навигация доступна также в браузере; нативные режимы окна доступны в настольном приложении.

## Справочные цены

Эти поля **необязательны**. Собственный ориентир за тонну помогает оценить стоимость груза и состава астероида по выбранной вами цене.

- Заполненное поле задаёт ваш ориентир.
- Пустое поле использует последнюю доступную цену из игрового рынка. Чтобы вернуть этот вариант, очистите поле и сохраните настройки.
- Если нет ни своего ориентира, ни наблюдаемой цены, стоимость остаётся неизвестной.

Автоматическая цена, источник и время наблюдения показываются рядом. Старое наблюдение сохраняет свою дату; сам факт его отображения не гарантирует текущую цену продажи.

Поиск покупателей и продавцов во вкладке «Торговля» использует рыночные наблюдения своего источника вместе со спросом и запасом. История операций и статистика хранят фактические суммы записанных сделок. Справочные ориентиры относятся к локальным оценкам стоимости.
