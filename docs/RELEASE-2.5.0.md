# ED Copilot 2.5.0

- The English README now contains eleven new 1920 × 1080 fullscreen screenshots, captured with an isolated English demonstration profile. The Russian README retains its original Russian screenshots.
- Reworked all nine Academy courses into expanded, original lessons in English and Russian: trading alerts, wing mining missions, Booze Cruise, carrier trading and ownership, group operations, Odyssey, combat preparation and Robigo passenger runs.
- Added practical Copilot workflows, worked fictional examples, preparation checklists, decision points and recovery steps. The 27 lessons retain their existing progress, bookmarks, answers and reading positions when switching language or updating.
- Improved English descriptions on ship and engineer pages, reference articles, carrier-route assumptions and colony advice.
- Added a dedicated offline documentation-capture mode and automated checks for screenshot language, fullscreen geometry, asset checksums and separation of English and Russian README images.

The interface and Academy support English and Russian. New profiles start in English; existing language preferences are preserved.

Before updating, fully exit ED Copilot using File → Exit or its notification-area icon. Personal settings, connections and plans remain in the existing profile.
