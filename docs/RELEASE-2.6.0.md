# ED Copilot 2.6.0

- Added Commander Ranks: eight individual progress bars, all rank ladders, dated journal observations, promotion history and concise advancement guides. Rank-specific rewards include ships, system permits and applicable discounts. Missing progress stays unknown; Inara's own ranking is not used.
- Added Politics: public community goals, personal journal contributions, Powerplay powers and indexed system searches, local faction influence, active and pending states, reported conflict pairings and Thargoid system observations. Each data block has its own source and time; successful cached observations remain available offline.
- Added quiet automatic updates, enabled by default and controlled in Settings. Downloads come from stable releases in this GitHub repository and are checked against the release asset digest and SHA256SUMS. Installation waits until the application fully exits. The next launch shows the installed version's changes.
- Setup now offers independent Start Menu and desktop shortcut choices in English and Russian. Silent updates preserve the selected directory and shortcut choices.
- Added English/Russian interface scenarios, isolated political and rank fixtures, update verification tests, and installer upgrade checks.

Fully exit ED Copilot through File → Exit or the notification-area icon before installing this version. Closing the window to the tray keeps it running. Your profile, settings and plans remain in their existing directory.
