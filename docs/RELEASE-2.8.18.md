# ED Copilot 2.8.18

- Open **Settings → Controls** to edit Elite Dangerous Live button assignments, gamepad chords and axes.
- Choose separate control profiles for general controls, ship, SRV and on-foot play. Duplicate profiles and import or export `.binds` files.
- Create and restore control backups. Copilot backs up the current profiles before writing changes and checks that Elite Dangerous is closed.
