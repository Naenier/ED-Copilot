# Проверка отзывчивости

Версия 2.1.1 устраняет расчёт полной исследованной галактики в потоке окна. Долгие операции не должны мешать перемещению, изменению размеров, сворачиванию или закрытию окна.

Обычный `build.ps1 -Smoke -Package -Installer` запускает проверки модели, интерфейса на небольшом профиле и интерфейса на большой синтетической истории. Большой набор содержит 300 систем и 3000 тел с материалами и кольцами. Данные создаются во временной папке, сеть отключена; рабочий профиль не используется.

Отчёты `dist/smoke-native.json` и `dist/smoke-stress.json` содержат `interactionTimings`: время повторного разворачивания/восстановления, сворачивания, F11 и переходов между разделами. Проверяются реальные обработчики HTML-кнопок и нативные команды окна. Зависание прерывает проверку; время зависит от процессора, масштаба Windows и состояния машины.

Для самостоятельной проверки большого профиля:

```powershell
& '.\dist\ED Copilot.exe' --demo --stress
```

Это отдельный демонстрационный профиль без сети. Проверьте многократное разворачивание, F11, сворачивание и восстановление, разные разделы и длинные таблицы. `--stress` разрешён только вместе с изолированным режимом проверки.

Модульные проверки дополнительно блокируют подставной backend и проверяют, что обновления окна объединяются в ограниченную очередь, а оконные команды выполняются после возврата WebView2 callback. Отдельные тесты сравнивают содержимое экранов, действий и оверлеев полного и облегчённого снимков, включая данные для Inara.

Синтетические Go benchmarks находятся в `internal/app/online_responsiveness_test.go`, `internal/app/snapshot_scoped_test.go` и `internal/nativeui/modern_perf_windows_test.go`. Они не обращаются к личным журналам, ключам или внешним сервисам. Крупный полный снимок намеренно дорог; профиль CPU/памяти содержит только синтетические данные.
