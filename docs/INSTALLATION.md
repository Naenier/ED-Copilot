# Установка и обновление ED Copilot

## Установщик для Windows

Запустите `ED-Copilot-2.1.2-Setup.exe`. Установка доступна обычному пользователю Windows 10/11 x64 и по умолчанию выполняется в `%LOCALAPPDATA%\Programs\ED Copilot`. На экране выбора папки можно указать другой доступный каталог, например `C:\Games\ED Copilot`.

Установщик добавляет ED Copilot в меню «Пуск» и список установленных приложений Windows. Ярлык на рабочем столе можно включить отдельной галочкой. После установки приложение можно запустить с последнего экрана.

Для интерфейса требуется Microsoft Edge WebView2 Runtime. Если компонент уже установлен, дополнительных действий нет. Если его нет, мастер предлагает запустить официальный установщик Microsoft; для загрузки компонента потребуется интернет. Сам ED Copilot устанавливается без запроса прав администратора. При отсутствии прав записи в выбранную папку укажите папку своего пользователя.

## Обновление

Полностью завершите ED Copilot через его значок в области уведомлений Windows → «Выход», затем запустите новый установщик. Простое закрытие главного окна оставляет приложение работающим. Установщик обнаруживает работающий ED Copilot и предлагает завершить его; он не принудительно останавливает процесс.

При повторной установке мастер предлагает прежнюю папку. Личный профиль находится отдельно: `%LOCALAPPDATA%\ED Copilot`. В нём хранятся планы, настройки, прогресс обучения, очереди и защищённые данные подключений. Установка и обновление не перезаписывают эти файлы.

Если раньше использовалась переносимая версия в `C:\Games`, выберите её папку вручную либо установите приложение в предложенную папку пользователя. Существующий профиль будет доступен приложению в обоих случаях.

## Удаление

Используйте «Параметры Windows» → «Приложения» → «Установленные приложения» → ED Copilot → «Удалить». Удаляется приложение и созданные им ярлыки. Личный профиль сохраняется для повторной установки. Пользовательские файлы, которые не входят в установочный пакет, также не удаляются.

Microsoft WebView2 — общий компонент Windows и других приложений. Удаление ED Copilot не удаляет его.

## Переносимая версия

Архив `ED-Copilot-2.1.2-windows-amd64.zip` остаётся доступен для запуска без установщика. Распакуйте его в доступную папку и откройте `ED Copilot.exe`. Он использует тот же профиль пользователя и требует установленного WebView2 Runtime.

## Сборка установщика

```powershell
.\build.ps1 -Package -Installer -Smoke
```

Команда проверяет проект, создаёт переносимый архив и установщик, выполняет smoke приложения и установщика. Результаты находятся в `dist`: EXE приложения, ZIP, `ED-Copilot-2.1.2-Setup.exe`, `SHA256SUMS.txt` и отчёты smoke. `-Installer` можно использовать отдельно от `-Package`.

Компилятор Inno Setup 7.1.1 загружается с официального GitHub разработчика, проверяется по закреплённому SHA-256 и подписи Pyrsys B.V. и разворачивается в переносимом режиме внутри `dist/tools`. В Windows он не регистрируется как установленная программа. Bootstrapper WebView2 загружается по официальной ссылке Microsoft и проверяется по Authenticode-подписи Microsoft Corporation до включения в пакет.

Установочный smoke использует отдельный идентификатор приложения, собственную папку внутри `dist` и тестовые ярлыки внутри этой папки. Он проверяет блокировку работающего процесса по mutex, отказ при отсутствующем Runtime в автоматическом режиме, установку, обновление, запуск на синтетических данных и удаление. Он не устанавливает системные компоненты и не использует реальные ключи. Контрольные суммы файлов рабочего профиля сравниваются до и после проверки.

Для автоматического развёртывания используется `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART`. Если Runtime отсутствует, такая установка завершается с ошибкой, пока WebView2 не подготовлен отдельно либо явно не передан `/INSTALLWEBVIEW2`. Этот параметр разрешает официальный Microsoft bootstrapper; его загрузке Runtime нужен интернет.

Только в одноразовой среде GitHub Actions скрипт `scripts/installer-runtime-ci.ps1` может подготовить Runtime автоматически перед проверкой интерфейса. На обычном компьютере этот CI-скрипт отказывается запускаться.
