# ED Copilot 2.4.1

- The main README is now in English. A complete Russian version remains available as `README.ru.md`, with links between both versions.
- New profiles start in English, including the loading screen. Existing English or Russian preferences are preserved. You can change the interface language in Settings.
- Added the missing spacing below the exobiology system-survey card, separating it from the planet and sample-tracker cards at all window widths.

The interface supports English and Russian. Academy lessons currently remain in Russian.

Before updating, fully exit ED Copilot using File → Exit or its notification-area icon. Personal settings, connections and plans remain in the existing profile.
