# Товарные идентификаторы и названия

`lib/commodity-names.json` сгенерирован непосредственно из первичных таблиц EDCD/FDevIDs:

- [commodity.csv](https://github.com/EDCD/FDevIDs/blob/master/commodity.csv) — обычные товары, материалы рынка и грузы;
- [rare_commodity.csv](https://github.com/EDCD/FDevIDs/blob/master/rare_commodity.csv) — редкие товары.

Ключи — нормализованные символы журнала и английские названия. Значение каждого ключа: `[английское название, символ Frontier]`. Канонический символ имеет приоритет над совпавшим псевдонимом названия. Отдельный `commodity-ru.json` содержит русские подписи интерфейса.

Первичный README EDCD предупреждает, что таблицы могут быть неполными, а английское игровое название может отличаться от обозначения в CAPI или EDDN. Таблица не содержит рыночных цен, спроса и наблюдений игроков. Актуальные данные рынка запрашиваются отдельно.

Для обновления из исходников, с установленным Node.js:

```powershell
node scripts/generate-commodity-names.cjs
```

Команда загружает две CSV-таблицы, добавляет только отсутствующие товары планетарной добычи из собственного `lib/catalog.cjs` и записывает JSON вместе с уведомлением `lib/COMMODITY-DATA-NOTICE.txt`. Существующий JSON не используется как вход генерации.

Для повторения генерации из сохранённых копий первичных таблиц:

```powershell
node scripts/generate-commodity-names.cjs --source-dir C:\путь\к\csv
```

В папке должны быть `commodity.csv` и `rare_commodity.csv`. Их контрольные суммы и число строк записываются в уведомление о данных. Игровые названия и идентификаторы сохраняют права Frontier Developments; лицензия кода приложения не подменяет условия использования игровых данных.
